01 / 先认清五种对称操作

判定点群，只是在数分子有哪些“做完看不出来”的动作

对称元素 symmetry element 是几何对象（轴、平面、点）；对称操作 symmetry operation 是绕着它做的动作。点群 point group 就是一个分子全部对称操作的集合。

E

恒等 identity

什么都不做。每个分子都有，没有它就构不成“群”。

Cn

真转动 proper rotation

绕轴转 360°/n。阶最高的那条轴叫主轴 principal axis，定为 z。本题两个分子都只有 C2。

σ

反映 reflection

对一个平面照镜子。含主轴的叫 σv（vertical），垂直于主轴的叫 σh（horizontal）。

i

反演 inversion

每个点穿过中心，到对面等距处：(x, y, z) → (−x, −y, −z)。

Sn

旋转反映 improper rotation

先转 360°/n，再对垂直于该轴的平面反映。S1 = σ，S2 = i。

唯一的判据：做完这个动作以后，每个原子都落在同种原子原来的位置上——分子和原来不可区分。哪怕只有一个原子落空，就不是对称操作。

位置约束：所有对称元素都必须穿过分子的质心 center of mass，因为任何对称操作都不能挪动质心。下面的 3D 模型都已把质心放在原点。

Schoenflies 判定流程：邻二氮菲SnCl₂ 走过的路

切换上面的分子，看两条路径——它们一模一样。

  1. 1

    是线性分子吗？

    否三个六元环稠合成一个平面，原子并不排在一条直线上。Sn 上有一对孤对电子（AX₂E），分子是弯的；气相实测键角 98.1°。

    若“是”：有 i → D∞h，无 i → C∞v

  2. 2

    有两条以上 n ≥ 3 的高阶轴吗？

    否中环看起来像正六边形，但整个分子没有 C3 或 C6；两个外环和两个 N 都只在一侧。三原子的弯曲分子最多只有一条 C2。

    若“是”→ 立方家族：Td、Oh、Ih 等（四面体、八面体、二十面体）

  3. 3

    有转动轴 Cn 吗？最高阶 n 是多少？

    有，n = 2C2 在分子平面内，竖直穿过 C5–C6 键中点和 C10a–C10b 键中点——它不穿过任何原子。这就是主轴 z。C2 穿过 Sn，平分 Cl–Sn–Cl 角。这就是主轴 z。

    若一条转轴都没有 → Cs（有 σ）、Ci（有 i）或 C1

  4. 4

    有 n 条（这里是 2 条）垂直于主轴的 C2 吗？

    否候选只有两条：垂直于分子平面的 C2(x)，和平面内水平的 C2(y)。两者都把底部“湾区”的两个 N 转到顶部，而顶部是 C5、C6——落空。候选 C2(x)、C2(y) 都会把向下张开的两个 Cl 转到 Sn 上方——那里只有孤对电子，没有原子。

    若“是”→ D 家族：再看 σh（Dnh）、n 个 σd（Dnd）或都没有（Dn）

  5. 5

    有垂直于主轴的镜面 σh 吗？

    否唯一的候选是过质心、垂直于 z 的 xy 平面。它把下方的 N 映到上方——落空。唯一的候选 xy 平面把两个 Cl 从 Sn 下方映到上方——落空。

    若“是”→ Cnh

  6. 6

    有 n 个（这里是 2 个）包含主轴的镜面 σv 吗？

    有 2 个一个是分子平面本身 σv′(yz)；另一个与它垂直、也含 C2，把左半个分子映成右半个——σv(xz)。分子平面 σv′(yz)（含 Sn 和两个 Cl）；以及垂直于它、只穿过 Sn 的 σv(xz)，交换两个 Cl。

    若“否”→ 再查 S2n：有 → S2n，无 → Cn

  7. ✓

    C2v

    群元素 {E, C2, σv(xz), σv′(yz)}，阶 h = 4。两个分子走的是同一条路径：点群只记录“有哪些对称元素”，与分子大小、原子种类、键角多少都无关。

04 / 几何决定点群

SnCl₂ 为什么是弯的

点群只看几何。SnCl₂ 的整道题其实取决于一个化学判断：分子是直的还是弯的。画成直线就会得到 D∞h——这是这道题最常见的错误答案。

价层电子对互斥理论 VSEPR

  1. Sn 是第 14 族，价层 4 个电子（5s²5p²）。Sn(II) 用其中 2 个与两个 Cl 成键。
  2. 剩下 2 个电子成为一对孤对电子 lone pair。
  3. 电子域 = 2 个成键 + 1 个孤对 = 3 → 电子对排成平面三角形；只看原子就是弯曲形（AX₂E）。
  4. 孤对电子比成键电子对更占地方，把两个 Cl 往下压：键角小于理想的 120°。

同一把量角器上的三个角

实测角 98.1° 比 120° 小得多。常见的解释是：重的主族元素的 5s 孤对电子 s 成分高，成键主要靠近乎纯的 p 轨道，所以键角向 90° 靠拢（惰性电子对效应 inert-pair effect）。这个解释影响的只是角度大小；只要不是 180°，点群就都是 C2v——在 02 节的滑块上可以验证。

注意物态：固体 SnCl₂ 中 Sn 通过氯桥彼此相连形成链状结构，不是孤立的 SnCl₂ 分子。题目问的是孤立分子，也就是气相单体。

06 / 常见错误

这道题容易错在哪

  • 把邻二氮菲当成 D2h。那是蒽（线形稠合）的点群。邻二氮菲角形稠合，两个 N 都在“湾区”一侧，垂直于主轴的两条 C2 都会把 N 送到没有 N 的地方。
  • 忘了分子平面本身也是镜面。任何平面分子都至少有这一个 σ。它不挪动任何原子，但仍是一个独立的操作——打开 02 节的“p 轨道”开关，执行 σv′(yz)，看垂直于平面的 p 轨道两瓣如何对调。
  • 把 SnCl₂ 画成直线，答 D∞h。Sn(II) 有一对孤对电子，AX₂E 是弯曲形。线形的是 HgCl₂、BeCl₂ 这类价层没有孤对的 AX₂。
  • 用固态结构判断 SnCl₂。晶体里是氯桥连接的链；题目问的是孤立分子（气相单体）。
  • 把 σv 和 σh 搞混。σh 必须垂直于主轴。C2v 里的两个镜面都包含 C2 轴，所以都是 σv。
  • 把对称元素放错位置。邻二氮菲的 C2 不穿过任何原子，而是穿过 C5–C6 和 C10a–C10b 两根键的中点；所有元素都必须过质心。
  • 以为 B1/B2 标签写反了就是错。那只是坐标约定不同（见 05 节末尾），点群本身不受影响。

08 / 来源与核验

哪些是精确的，哪些是示意

  • 用户原图题目照片保存在本专题的 source/problem.png。原图把邻二氮菲竖着画（N 在右侧）；本页把 C2 轴放成竖直，只是转了个方向。
  • 精确两个分子的点群、各对称操作成立与否、原子交换表、群乘法（如 σv(xz)·C2 = σv′(yz)）、Γ3N 与 Γ振动 的约化结果。由 source/verify.mjs 从坐标出发重新穷举对称元素、判点群、约化，共 39 项检查，结果在 verification.json。
  • 近似（文献值）SnCl₂ 气相键角 98.1°（气相电子衍射，Nasarenko 等 1985）。绘图用 Sn–Cl = 2.34 Å，文献中实验和理论值多在 2.33–2.39 Å。点群结论与这些数值无关：60°–179.9° 之间每隔 0.1° 都已验证为 C2v。
  • 教学示意邻二氮菲用理想正六边形搭建（C–C、C–N 均取 1.40 Å，C–H 1.08 Å），真实分子键长略有差别，但对称性完全相同。原子球大小、孤对电子“气球”、p 轨道两瓣的大小和位置都是示意。HgCl₂ 的键长也是示意值。
